网页发布器

拖入网页文件夹或 index.html → 自动建仓库、推送、开 Pages，直接给你网址。

纯前端 · 不装软件

1 · 授权

令牌只保存在你本机浏览器（localStorage），只会发往 api.github.com，不经过任何第三方服务器。 建议用只含 repo 权限的经典令牌，用完随时吊销；不勾「记住」则关闭页面即失效。

2 · 选择网页

把网页文件夹，或 index.html 拖到这里 也可以点这里选择

3 · 选项

进度

○校验 GitHub 账号
○分析站点内容
○预处理文件
○创建 / 复用仓库
○上传文件
○开启 GitHub Pages
○等待构建完成
○上线验收

日志


  


  

    

      它会自动处理哪些坑 / 有哪些限制
      

        自动处理：根路径 /css/a.css 转相对路径、引用大小写与真实文件名对齐、
        补 .nojekyll、单页应用补 404.html、排除 node_modules 与隐藏垃圾、
        识别藏在 dist/ 里的站点根、发布前检查超大文件（>100MB）和疑似密钥。
        


        限制：免费账号只能从公开仓库发布 Pages；站点上限 1GB、单文件 100MB；
        构建约 10 次/小时；只托管静态文件、没有后端；
        源码项目（需要 npm run build）请先在本地构建，再拖 dist/ 进来；
        非 UTF-8 编码的页面会原样上传、不做引用改写。
